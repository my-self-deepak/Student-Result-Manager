# Student Result Manager

A beginner-friendly Python project for managing student marks and results.

## Features
- Add student records
- View all students and their marks
- Check pass or fail status
- Delete student records
- Validate marks between 0 and 100
- Save and load data using JSON
- Handle invalid input

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- JSON
- Exception Handling

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run `main.py`.

## Learning Outcomes
Practiced Python classes, dictionaries, loops, functions, file handling, JSON, and error handling.
