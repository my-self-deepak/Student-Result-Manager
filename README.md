# Student Result Manager

A Python-based application to manage student records and check academic results. This project was built to practice object-oriented programming, file handling, JSON data storage, and exception handling.

## Features

- Add student records with marks
- View all saved student records
- Check whether a student has passed or failed
- Delete student records
- Validate marks between 0 and 100
- Prevent duplicate student names
- Save and load records using JSON
- Handle invalid numerical input

## Technologies Used

- **Language:** Python
- **Concepts:** Object-Oriented Programming (OOP), classes, methods, dictionaries, loops, and conditional statements
- **Data Storage:** JSON
- **Error Handling:** `try-except`

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python main.py
```
